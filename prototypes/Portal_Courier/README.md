# Portal Courier — Godot 4 小遊戲

## 玩法
在 90 秒內收集 5 枚訊號核心，避開巡邏無人機，再抵達右側傳送門撤離。碰撞會損失生命並回到起點；生命歸零或倒數結束即失敗。

## 操作
- A/D 或 ←/→：左右移動
- Space、W 或 ↑：跳躍
- E：EMP 脈衝，暫時癱瘓附近無人機
- R：任務結束後重新開始

## 執行
使用 Godot 4.2 或更新版本開啟 `project.godot`，按 F5 執行。全程使用 Godot 內建繪圖與碰撞形狀，不需外部素材。
