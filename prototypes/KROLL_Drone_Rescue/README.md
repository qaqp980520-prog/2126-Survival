# KROLL Drone Rescue｜Godot 4 prototype

## Gameplay
Pilot a KROLL rescue drone through electromagnetic interference zones, rescue four survivors, and reach the extraction zone. Battery drains over time; green battery pickups restore power. EMI zones accelerate battery loss.

## Controls
- WASD or arrow keys: move
- Shift: boost (uses more battery)
- Touch a yellow survivor marker: rescue automatically
- Touch a green battery marker: recharge automatically
- R: restart after the mission ends

## Files
- `project.godot`: project settings and main scene.
- `scenes/main.tscn`: main Node2D scene.
- `scripts/main.gd`: gameplay and drawing logic.
