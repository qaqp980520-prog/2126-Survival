# KROLL Signal Runner — Godot 4

A small 2D arcade game built with Godot's built-in drawing APIs (no external assets).

## Objective
Recover all 8 yellow signal shards before the 75-second window closes. Avoid the red patrol drones. Press **E** to trigger an EMP pulse that temporarily disables nearby drones.

## Controls
- **WASD / Arrow keys** — Move
- **E** — EMP pulse (4-second cooldown)
- **R** — Restart after victory or defeat

## Run
Open `project.godot` in Godot 4.2 or newer and press **F6/F5** (F5 runs the project).

## Validation
- Source files committed to GitHub: project settings, main scene and gameplay script.
