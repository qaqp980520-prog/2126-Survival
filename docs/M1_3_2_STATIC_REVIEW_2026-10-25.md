# M1.3.2 合併後靜態複核｜2026-10-25

- 複核對象：合併後 `scripts/world.gd`、`project.godot`、`scenes/main.tscn` 與 README。

## 靜態複核結果
- M1.3.2 ZIP 的 `world.gd` 是基於 M1.3.1 版本延伸，作物存檔欄位與重複讀檔清理同時存在；因此不是把兩份 patch 生硬疊在基底上。
- `_ready()` 的順序是建立材質、建立世界、建立玩家／UI，最後讀檔；這讓靜態世界作物在 `_restore_world_state()` 執行前已存在，可用固定 `world_crop_id` 移除已採集作物。
- 動態作物與玩家種植作物在還原前先從 `interactables` 移除並排隊釋放，之後才重建；此流程意圖避免重複讀檔造成邏輯陣列累積重複節點。
- 作物文字標籤已改成作物／種植節點的子節點，預期在父節點刪除時一起釋放。
- 存檔版本為 2，載入接受 v1 與 v2；v1 沒有 `world_state` 時會保留新遊戲生成的靜態世界狀態。

## 尚未解決的風險
1. `_load_game()` 仍未完整驗證 `inventory`、座標陣列及 world-state 內各欄位的型別／數值範圍；格式損壞的 JSON 可能被部分套用。
2. 固定野生作物的採集狀態以名稱與座標組合成 ID。若日後改動固定作物名稱或座標，舊存檔可能無法識別該作物；正式版應改用穩定且明確的唯一 ID。
3. 世界存檔目前仍未保存動物死亡狀態與戰利品掉落物，這些不在本輪作物修補範圍。
4. 新的 `SurvivalInventory`／`SurvivalWorldBridge` 仍未接入此 M1.3 原型；此版本仍使用舊的 inventory Dictionary，不能宣稱共用背包已整合。
5. 沒有 Godot 4 執行檔，因此未能執行 GDScript parser、啟動專案或存檔往返測試。
