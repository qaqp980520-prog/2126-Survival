# M0.1.98 — Backrooms Level 4 Office and Entity Roster

## Purpose

Add a Level 4 destination to the existing legacy Backrooms portal playground, with a distinct deterministic entity whitelist and an office-interior visual treatment.

## Gameplay/content contract

- Portal destinations now include Level 4 while preserving Levels 0–3.
- Level 4 permits only `duller` and `deathmoth`.
- Duller spawn chance: 5%; Deathmoth spawn chance: 8%; both use unique stable hash salts so cell results remain deterministic.
- Level 4 uses a dedicated office-wall SVG texture and a muted charcoal carpet palette.
- Duller and Deathmoth are visual prototypes only in this legacy playground. They do not yet have AI, damage, attack, collision-proxy, navigation, or save-state behavior.
- Existing Level 0–3 rosters and spawn probabilities remain unchanged.

## Dependencies and import

- Godot 4.3 root project.
- Existing `BackroomsPortalPlayground.tscn`, `BackroomsEntityDirector`, `BackroomsPortalDirector`, and `BackroomsPortalPlayground` production cell builder.
- No new third-party dependencies.
- The SVG is loaded through a new `preload()` constant and imported by the existing root-project import step.
- Entity geometry is generated by the existing box helper plus a new sphere helper; no external model files are required.

## Validation

- Entity-director regression checks the exact Level 4 whitelist, deterministic selection, both entities appearing over a bounded 81×81 cell scan, and fail-closed unknown levels.
- Portal-director regression checks the complete destination roster includes Level 4.
- Production factory geometry regression exercises all eight entity factories (six existing plus Duller and Deathmoth), checks root metadata, mesh counts, material resources, and transformed mesh AABBs against the cell envelope.
- The Level 4 factory test also verifies that the dedicated office-wall texture is selected.
- Exact-head GitHub Actions Godot 4.3 Full Compatibility Gate and Xvfb/Mesa factory validation are required before marking this asset accepted.

## Limitations and next steps

- Duller and Deathmoth are static visual prototypes; AI/physics behavior belongs in the separate newer BackroomsMazeCellRuntime architecture after its parent stack is reviewed.
- No collision, navigation, attack, pursuit, persistence, GPU hardware, FPS, or mobile-device claim is made by this asset.
- After independent review, integrate parent-first through PR #425 → #426 → this PR, rerunning exact-head validation after every parent synchronization.
