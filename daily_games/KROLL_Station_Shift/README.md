# KROLL Station Shift M0.1

A deterministic turn-based station operations game built with Godot 4.3+.

## Objective

Keep Energy, Oxygen and Hull above zero for six cycles, then finish with at least 5 Energy, 5 Oxygen and 30 Hull.

## Controls

- 1, 2, 3: select Power, Life Support or Repairs.
- Minus / equals: move one crew member away from or into the selected station.
- Enter / Space: run the current cycle.
- R: restart the current scenario.
- N: switch to the next scenario.
- Every station must keep at least one crew member; exactly five crew must be assigned before a cycle can run.
- The on-screen plus/minus and action buttons support mouse and touch.

## Scenarios

Dockside Blackout, Ridge Research and Floodplain Habitat each have six deterministic events. The rules tests include a complete winning crew allocation for every authored scenario.

## Import

Open daily_games/KROLL_Station_Shift/project.godot in Godot Project Manager.

No external assets, add-ons, audio files or network access are required.
